# Bigfoot Commander website

Four-page accessible website: Home, Meet the Commanders, Our Story, Shop.

**Status:** HTML/CSS/JavaScript uploaded. **Image files still need uploading** into the `assets/` directory. The website images will be broken until those seven files are added.

## Upload the seven images
Extract `bigfoot-commander-images-only.zip`, open `https://github.com/BigFootCommander/bigfoot-commander/tree/main/assets` (create assets folder if needed via GitHub's Upload files button at repository root), and upload all seven image files with exactly these names:

- `commander-trio.jpg`
- `forest-trio.png`
- `glowsquatch.jpg`
- `logo.png`
- `og.png`
- `oklahoma-campfire.png`
- `shadow.png`

Every site page refers to these paths under `assets/`.

## Publish
GitHub repository **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Site preview URL: https://bigfootcommander.github.io/bigfoot-commander/ after Pages has finished publishing.

The live `bigfootcommander.com` domain remains on the old site until DNS is deliberately changed.

Features: semantic landmarks, keyboard-visible focus, descriptive alt text, current-page navigation cues, responsive layout, reduced motion support, and system/light/dark appearance toggle. Checkout is not connected yet.
